Real-World Impact: AHV International

At AHV International, I designed and delivered end-to-end automation tools that dramatically improved operational efficiency and decision-making across the business.

Automated Report Generation System

Designed a powerful reporting pipeline that reduced manual work from days to seconds. Leveraged Python, Excel automation, and branded templates to ensure consistent, high-quality output. Reports supported multi-million pound business decisions in agriculture and animal health.

Data Analysis & Strategic Insights

Built systems to extract, clean, and analyse large datasets across multiple sources — including internal spreadsheets and third-party portals. Delivered actionable insights on milk quality, fertility trends, and herd health, crucial for consultants and business leaders.

Custom Web Scraping Tools

Developed secure scripts to automatically fetch critical data from external sites (e.g. CIS, Herd Companion), saving dozens of hours weekly and eliminating human error.

User-Friendly Application for Non-Technical Staff

Engineered a GUI-based app allowing staff to generate tailored reports with zero coding or Excel knowledge. Designed for use across multiple locations — intuitive for users, yet powered by a complex automation backend.

Digital Transformation & Workflow Automation

Replaced fragmented manual processes with seamless digital workflows, integrating file downloads, email scraping, spreadsheet parsing, PDF generation, and commentary writing using AI.

~/clients/sf-barbers LIVE

Complete Digital Solution: S&F Barbers

I developed a comprehensive web-based booking management system for S&F Barbers in Mold, completely digitalizing their appointment booking process and providing sophisticated administrative tools for modern barber shop operations.

Complete User Authentication System

Built secure user registration with invite password protection, dual-tier access for regular users and admin accounts, and session-based login management with Werkzeug password hashing.

Advanced Booking Calendar System

Created interactive 14-day calendar view with hourly time slot booking, real-time availability checking, conflict prevention, and responsive Bootstrap interface with visual distinction between available and booked slots.

Flexible Schedule Management

Implemented custom business hours override system, admin ability to set specific hours for any date, business closure management for holidays, and 30-day schedule overview with visual calendar.

Dual Booking System

Developed both registered user booking with full profile integration and guest booking system for walk-in customers, plus admin booking interface with real-time user search functionality.

Professional Email Automation

Integrated automated confirmation emails for all bookings, cancellation notifications with professional templates, Gmail SMTP integration, and branded email templates with S&F Barbers styling.

// key outcomes

  • Complete digitization of appointment booking process
  • 24/7 customer booking access with automated confirmations
  • Reduced manual administrative work significantly
  • Professional admin tools for managing registered and walk-in appointments
